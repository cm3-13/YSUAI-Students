# YSU-AI

> 燕山大学人工智能学院学生知识库与课程攻略平台 | Open knowledge base and course survival guides for YSU School of AI students.

## 简介

YSU-AI 是一个面向燕山大学人工智能学院同学的民间 Wiki，聚合课程资料、学习路线与经验文章，帮助后来者少走弯路。

## 目录速览

| 模块 | 说明 | 入口 |
|------|------|------|
| 学习攻略 | 培养方案、课程攻略、学习经验 | [`docs/学习攻略.md`](docs/学习攻略.md) |
| 科研攻略 | 科研概览、细分方向导航 | [`docs/科研攻略.md`](docs/科研攻略.md) |
| 职场攻略 | 实习与就业经验分享 | [`docs/职场攻略.md`](docs/职场攻略.md) |
| FAQ | 常见问题解答 | [`docs/FAQ.md`](docs/FAQ.md) |
| 贡献指南 | 如何参与贡献 | [`docs/贡献指南.md`](docs/贡献指南.md) |

## 快速开始

```bash
# 1) 安装依赖
npm install

# 2) 本地开发
npm run docs:dev

# 3) 构建产物
npm run docs:build

# 4) 本地预览构建结果
npm run docs:preview
```

## 推荐贡献流程

1. Fork 本仓库并创建分支。
2. 在 `docs/` 下新增或修改内容。
3. 本地运行 `npm run docs:dev` 检查展示效果。
4. 提交 PR，描述改动目的与影响范围。
