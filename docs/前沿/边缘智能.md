# 边缘智能

边缘智能（Edge AI）将深度学习模型部署到手机、嵌入式设备等终端，在本地完成推理，兼顾低延迟与隐私保护。

## 核心概念

- **模型轻量化**：MobileNet、EfficientNet 等轻量架构
- **硬件加速**：NPU、GPU、DSP 等专用推理芯片
- **推理框架**：TensorRT、ONNX Runtime、MNN、NCNN
- **联邦学习**：数据不出端的分布式训练范式

## 入门路线

1. 学习 CNN 轻量架构设计（深度可分离卷积等）
2. 掌握 ONNX 模型导出与转换
3. 在树莓派 / 手机上部署一个分类或检测模型
4. 了解模型量化的原理（INT8 / FP16）
