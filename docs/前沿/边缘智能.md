# 边缘智能

<TechAnimation type="edge-ai" />

边缘智能（Edge AI）将深度学习模型部署到手机、嵌入式设备等终端，在本地完成推理，兼顾低延迟与隐私保护。

## 核心概念

| 概念 | 说明 |
|------|------|
| 轻量架构 | MobileNet、EfficientNet、ShuffleNet |
| 模型量化 | FP32 → INT8/INT4，降低存储与算力 |
| 推理引擎 | TensorRT、ONNX Runtime、MNN、NCNN |
| 知识蒸馏 | 大模型指导小模型训练 |
| 联邦学习 | 数据不出端的分布式训练 |

## 经典模型

- **MobileNetV3**：深度可分离卷积 + SE 注意力
- **EfficientNet**：复合缩放（宽度/深度/分辨率）
- **TinyBERT**：面向移动端的 BERT 蒸馏
- **YOLO-Nano**：超轻量目标检测

## 部署流程

```
训练框架(PyTorch/TF) → 导出 ONNX → 图优化
  → 量化(PTQ/QAT) → 硬件编译 → 端侧推理
```

## 入门路线

```
CNN轻量架构 → ONNX导出与转换 → 树莓派/手机部署
  → INT8量化 → 联邦学习基础 → 性能调优
```
