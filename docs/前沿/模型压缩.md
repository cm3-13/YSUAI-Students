# 模型压缩

模型压缩旨在减小深度学习模型的参数量与计算量，使其能在资源受限的设备上高效运行。

## 核心概念

- **剪枝（Pruning）**：移除不重要的权重或通道
- **量化（Quantization）**：降低数值精度（FP32 → INT8）
- **知识蒸馏（Distillation）**：用大模型（Teacher）指导小模型（Student）学习
- **低秩分解**：将权重矩阵分解为低秩近似

## 入门路线

1. 理解模型参数量与 FLOPs 的计算方式
2. 实践一次 INT8 训练后量化（PTQ）
3. 尝试知识蒸馏（如 DistilBERT 的思路）
4. 对比压缩前后模型的精度与推理速度
