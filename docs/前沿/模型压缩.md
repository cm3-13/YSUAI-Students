# 模型压缩

<TechAnimation type="model-compression" />

模型压缩旨在减小深度学习模型的参数量与计算量，使其能在资源受限的设备上高效运行。

## 核心概念

| 概念 | 说明 |
|------|------|
| 剪枝 | 移除不重要的权重或通道（结构化/非结构化） |
| 量化 | 降低数值精度（FP32→INT8→INT4） |
| 知识蒸馏 | Teacher-Student 范式迁移知识 |
| 低秩分解 | 矩阵分解降低参数量 |
| 权重共享 | 聚类/哈希减少存储 |

## 经典方法

- **Deep Compression**（Han et al.）：剪枝+量化+霍夫曼编码三阶段
- **DistilBERT**：BERT 蒸馏，保留 97% 精度、参数减 40%
- **GPTQ / AWQ**：大模型训练后量化到 INT4/INT3
- **LoRA**：低秩适配，微调时只更新低秩矩阵

## 压缩方法对比

| 方法 | 压缩比 | 精度损失 | 部署难度 |
|------|--------|----------|----------|
| 剪枝 | 中 | 低-中 | 需要稀疏算子 |
| 量化 | 高 | 低 | 低（主流推理引擎支持） |
| 蒸馏 | 中 | 低 | 需要重新训练 |
| 低秩分解 | 中-高 | 中 | 需要网络结构改动 |

## 入门路线

```
参数量/FLOPs计算 → INT8训练后量化 → 知识蒸馏实践
  → 大模型量化(GPTQ/AWQ) → 端到端压缩Pipeline
```

- **1-bit LLM**：BitNet 等极端量化
- **稀疏激活**：MoE 架构只激活部分参数
- **自适应推理**：根据输入难度动态调整计算量
