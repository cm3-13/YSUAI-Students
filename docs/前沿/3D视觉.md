# 3D 视觉

<TechAnimation type="3d-vision" />

3D 视觉研究如何从二维图像或点云中理解三维世界，涵盖 3D 重建、点云理解、神经辐射场（NeRF）与 3D 高斯泼溅等技术。

## 核心概念

| 概念 | 说明 |
|------|------|
| 点云 | 三维空间中的无序点集 |
| NeRF | 用神经网络隐式表示辐射场 |
| 3D 高斯泼溅 | 显式高斯基元实时渲染 |
| 多视图立体（MVS） | 多张图像恢复稠密深度 |
| SLAM | 同时定位与地图构建 |

## 经典模型

- **PointNet / PointNet++**：直接处理无序点集的先驱
- **NeRF**：隐式神经表示，新视角合成
- **Instant-NGP**：多分辨率哈希加速 NeRF
- **3D Gaussian Splatting**：实时高保真渲染
- **DUSt3R**：无相机位姿的稠密重建

## 技术演进

```
传统多视图几何 → 深度学习(MVS/PointNet) → 隐式表示(NeRF)
  → 显式表示(3DGS) → 大规模重建/生成
```

## 入门路线

```
相机模型/多视图几何 → 点云基础(采样/配准)
  → NeRF原理与实践 → 3D Gaussian Splatting → 动态场景重建
```
