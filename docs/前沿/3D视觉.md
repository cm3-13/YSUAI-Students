# 3D 视觉

3D 视觉研究如何从二维图像或点云中理解三维世界，涵盖 3D 重建、点云理解、神经辐射场（NeRF）与 3D 高斯泼溅等技术。

## 核心概念

- **点云处理**：PointNet 系列直接处理无序点集
- **NeRF**：用神经网络隐式表示三维场景的辐射场
- **3D 高斯泼溅（3DGS）**：显式高斯基元的实时渲染方案
- **多视图立体（MVS）**：从多张图像恢复稠密深度

## 入门路线

1. 学习相机模型与多视图几何基础
2. 掌握点云的基本操作（采样、法向估计、配准）
3. 跑通一个 NeRF 或 Instant-NGP demo
4. 尝试 3D Gaussian Splatting 的开源实现
