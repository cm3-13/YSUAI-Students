# 语音与音频

语音与音频方向涵盖语音识别（ASR）、语音合成（TTS）、音乐生成、音频事件检测等任务，让机器能听懂、生成声音。

## 核心概念

- **语音识别（ASR）**：将语音转为文字（如 Whisper、Paraformer）
- **语音合成（TTS）**：将文字转为自然语音（如 VITS、ChatTTS）
- **语音大模型**：端到端语音理解与生成（如 GPT-4o、Qwen-Audio）
- **音乐生成**：AI 作曲与编曲（如 MusicGen、SunO）

## 入门路线

1. 学习信号处理基础（傅里叶变换、梅尔频谱）
2. 了解 CTC / Attention 两种语音识别范式
3. 用 Whisper 跑通一个语音转文字任务
4. 尝试用 VITS 或 GPT-SoVITS 做一次语音克隆
