# 语音与音频

<TechAnimation type="speech-audio" />

语音与音频方向涵盖语音识别（ASR）、语音合成（TTS）、音乐生成、音频事件检测等任务，让机器能听懂、生成声音。

## 核心概念

| 概念 | 说明 |
|------|------|
| ASR | 语音转文字（Whisper、Paraformer） |
| TTS | 文字转语音（VITS、ChatTTS） |
| 语音大模型 | 端到端语音理解与生成（GPT-4o、Qwen-Audio） |
| 音乐生成 | AI 作曲编曲（MusicGen、Suno） |
| 声纹识别 | 说话人身份验证 |

## 信号处理基础

- **短时傅里叶变换（STFT）**：时域 → 频域
- **梅尔频谱（Mel Spectrogram）**：模拟人耳感知的频谱特征
- **MFCC**：梅尔倒谱系数，经典语音特征
- **音高 / 能量 / 过零率**：基本声学特征

## 经典模型

- **Whisper**：OpenAI 多语言语音识别，鲁棒性强
- **VITS**：端到端高质量语音合成
- **MusicGen**：Meta 音乐生成模型
- **Qwen-Audio**：多模态音频理解大模型

## 入门路线

```
信号处理(FFT/梅尔) → CTC/Attention识别范式
  → Whisper实战 → VITS语音合成 → 多模态音频理解
```
