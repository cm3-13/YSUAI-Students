# 图神经网络

图神经网络（GNN）专门处理图结构数据，通过消息传递机制聚合邻居节点信息，在社交网络、分子设计、推荐系统等场景表现出色。

## 核心概念

- **消息传递（Message Passing）**：节点从邻居聚合特征
- **经典模型**：GCN、GAT、GraphSAGE、GIN
- **图级别任务**：分子性质预测、图分类
- **节点级别任务**：节点分类、链路预测

## 入门路线

1. 复习图论基础（邻接矩阵、度、路径）
2. 理解 GCN 的谱域推导与空间解释
3. 用 PyG（PyTorch Geometric）跑通 Cora 引用网络分类
4. 尝试分子属性预测（如 QM9 数据集）
