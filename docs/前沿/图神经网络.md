# 图神经网络

<TechAnimation type="graph-nn" />

图神经网络（GNN）专门处理图结构数据，通过消息传递机制聚合邻居节点信息，在社交网络、分子设计、推荐系统等场景表现出色。

## 核心概念

| 概念 | 说明 |
|------|------|
| 消息传递 | 节点从邻居聚合特征（Message Passing） |
| 图卷积 | 在图结构上定义卷积操作 |
| 图级别任务 | 图分类、分子性质预测 |
| 节点级别任务 | 节点分类、链路预测 |
| 图池化 | 图结构的下采样 |

## 经典模型

- **GCN**：图卷积网络，谱域理论基础
- **GAT**：图注意力网络，自适应邻居权重
- **GraphSAGE**：归纳式学习，支持未见节点
- **GIN**：图同构网络，理论表达力最强
- **SchNet / DimeNet**：分子图专用网络

## 消息传递范式

```
m_v = AGGREGATE({MSG(h_v, h_u, e_uv) : u ∈ N(v)})
h_v' = UPDATE(h_v, m_v)
```
