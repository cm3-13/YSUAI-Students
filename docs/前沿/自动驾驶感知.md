# 自动驾驶感知

<TechAnimation type="autonomous-driving" />

自动驾驶感知模块负责从摄像头、激光雷达、毫米波雷达等传感器中理解周围环境，是无人驾驶系统的核心环节。

## 核心概念

| 概念 | 说明 |
|------|------|
| BEV 感知 | 多视角图像统一到鸟瞰坐标系（BEVFormer） |
| 3D 目标检测 | 在三维空间中定位车辆、行人等目标 |
| 占据栅格 | 将环境离散化为 Occupancy Grid |
| 多传感器融合 | 互补摄像头语义与 LiDAR 几何信息 |
| 端到端 | 从原始输入直接到规划控制 |

## 经典模型

- **PointPillars**：将点云编码为伪图像，快速 3D 检测
- **BEVFormer**：用 Transformer 在 BEV 空间融合多相机
- **UniAD**：端到端自动驾驶统一框架（感知→预测→规划）
- **OccNet**：3D 占据预测，统一障碍物表示

## 传感器对比

| 传感器 | 优势 | 劣势 |
|--------|------|------|
| 摄像头 | 语义丰富、成本低 | 缺少深度、受光照影响 |
| LiDAR | 精确 3D 几何 | 成本高、天气敏感 |
| 毫米波 | 全天候、测速 | 分辨率低 |

## 入门路线

```
CV基础(检测/分割) → 点云处理(PointNet) → 多视图几何
  → BEV表示 → 多传感器融合 → nuScenes/Waymo 实战
```
