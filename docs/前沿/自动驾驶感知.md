# 自动驾驶感知

自动驾驶感知模块负责从摄像头、激光雷达、毫米波雷达等传感器中理解周围环境，是无人驾驶系统的核心环节。

## 核心概念

- **BEV（鸟瞰图）感知**：将多视角图像统一到鸟瞰坐标系（如 BEVFormer）
- **3D 目标检测**：在三维空间中定位车辆、行人等目标（如 PointPillars）
- **多传感器融合**：互补不同传感器的优劣势
- **端到端感知**：从原始传感器输入直接到规划决策

## 入门路线

1. 掌握计算机视觉基础（目标检测、语义分割）
2. 学习点云处理（PointNet、VoxelNet）
3. 了解 BEV 表示与占据栅格（Occupancy Grid）
4. 跑通 nuScenes 或 Waymo 数据集的基线模型
