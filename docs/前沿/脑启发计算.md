# 脑启发计算

脑启发计算借鉴大脑的信息处理机制，探索脉冲神经网络（SNN）、类脑芯片等新型计算范式，追求更低功耗、更高效率。

## 核心概念

- **脉冲神经网络（SNN）**：以脉冲时序编码信息，事件驱动计算
- **突触可塑性（STDP）**：基于脉冲时序的无监督学习规则
- **类脑芯片**：Intel Loihi、IBM TrueNorth 等神经形态硬件
- **ANN-SNN 转换**：将训练好的人工神经网络映射到脉冲网络

## 入门路线

1. 了解神经元模型（LIF、HH 模型）
2. 学习脉冲编码方法（频率编码、时间编码）
3. 用 SpikingJelly 或 Norse 框架搭建简单 SNN
4. 阅读 Loihi / Speck 等类脑芯片的介绍
