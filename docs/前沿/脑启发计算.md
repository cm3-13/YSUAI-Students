# 脑启发计算

<TechAnimation type="brain-computing" />

脑启发计算借鉴大脑的信息处理机制，探索脉冲神经网络（SNN）、类脑芯片等新型计算范式，追求更低功耗、更高效率。

## 核心概念

| 概念 | 说明 |
|------|------|
| 脉冲神经网络（SNN） | 以脉冲时序编码信息，事件驱动 |
| 突触可塑性（STDP） | 基于脉冲时序的无监督学习规则 |
| 类脑芯片 | Intel Loihi、IBM TrueNorth |
| ANN-SNN 转换 | 将传统网络映射到脉冲网络 |
| 脉冲编码 | 频率编码、时间编码、群体编码 |

## 神经元模型

- **LIF（Leaky Integrate-and-Fire）**：最常用的简化模型
- **HH（Hodgkin-Huxley）**：生物精确的离子通道模型
- **Izhikevich**：兼顾生物真实性与计算效率

## 与传统深度学习对比

| 维度 | ANN | SNN |
|------|-----|-----|
| 计算方式 | 矩阵乘法 | 脉冲事件驱动 |
| 能耗 | 较高 | 极低（稀疏激活） |
| 学习 | 反向传播 | STDP / ANN转换 |
| 时间建模 | 需要额外结构 | 天然时序性 |

## 入门路线

```
神经元模型(LIF) → 脉冲编码方法 → SpikingJelly/Norse实践
  → ANN-SNN转换 → 类脑芯片(Loihi) → 神经形态应用
```
