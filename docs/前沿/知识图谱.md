# 知识图谱

<TechAnimation type="knowledge-graph" />

知识图谱（Knowledge Graph）以「实体—关系—实体」三元组的形式组织世界知识，是搜索引擎、智能问答、推荐系统等应用的核心基础设施。

## 核心概念

| 概念 | 说明 |
|------|------|
| 三元组 | (Head, Relation, Tail)，知识的基本单元 |
| 本体 | 定义概念、属性与关系的共享词汇体系 |
| 知识嵌入 | 将实体/关系映射到低维向量空间（TransE、RotatE） |
| 知识推理 | 基于已有事实推断隐含知识（链式推理、规则挖掘） |
| 图谱构建 | 从文本/半结构化数据中抽取实体与关系 |

## 经典模型

- **TransE**：将关系建模为向量平移 `h + r ≈ t`
- **ComplEx**：在复数空间中建模不对称关系
- **R-GCN**：关系图卷积网络，聚合多关系邻居信息
- **KG-BERT**：用预训练语言模型编码三元组

## 应用场景

- **智能问答**：「刘德华的妻子是谁？」→ 图谱查询
- **推荐系统**：利用用户-物品-属性图谱增强推荐
- **金融风控**：企业关系图谱识别关联交易与风险
- **药物发现**：药物-靶点-疾病知识图谱辅助药物重定位

## 入门路线

```
图论基础 → 语义网络/Web Ontology → 知识抽取(NER/RE)
  → 图谱嵌入(TransE) → 图谱推理 → 实战构建
```
