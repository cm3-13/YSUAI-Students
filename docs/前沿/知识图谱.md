# 知识图谱

知识图谱（Knowledge Graph）以「实体—关系—实体」三元组的形式组织世界知识，是搜索引擎、智能问答、推荐系统等应用的核心基础设施。

## 核心概念

- **三元组 (Head, Relation, Tail)**：知识图谱的基本单元
- **本体 (Ontology)**：定义概念、属性与关系的共享词汇
- **知识推理**：基于已有事实推断隐含知识（如 TransE、RotatE）

## 入门路线

1. 学习图论基础与语义网络
2. 了解经典知识图谱项目：Wikidata、CN-DBpedia
3. 实践一个知识图谱构建流程（抽取 → 融合 → 推理）
4. 阅读 TransE、ComplEx 等嵌入表示论文
